## Blog

The blog merges two sources into one list (sorted by date):

1. **Local markdown posts** in `content/blog/<post-folder>/index.md` —
   published by `git push`, live only on this site
2. **Hashnode posts** — pulled from the RSS feed at build time

📖 **Full guide: [BLOG_PUBLISHING.md](./BLOG_PUBLISHING.md)** — folder
structure, frontmatter reference, images, drafts, troubleshooting.

Quick version:

```bash
mkdir -p content/blog/2026-08-01-my-post/images
# write content/blog/2026-08-01-my-post/index.md with frontmatter
git add content/blog && git commit -m "blog: my post" && git push
```

Never edit `src/data/posts.ts` — it's generated by `scripts/build-posts.mjs`.
