# Aman Kumar - Portfolio

👋 Hello everyone! This is my personal portfolio website showcasing my work as a **Data Scientist & AI/ML Engineer**.

## 🌐 Live Demo
[Visit Portfolio](https://aman123lug.github.io/my-portfolio)

## ✨ Features
- 🏠 **Home** - Introduction and hero section
- 💼 **Projects** - My GitHub projects and work experience
- 📝 **Blog** - Integrated with Hashnode (auto-syncs posts)
- 📬 **Contact** - Get in touch with me

## 🛠️ Tech Stack
- React + TypeScript
- Vite
- React Router
- Hashnode GraphQL API

## 🚀 Quick Start
```bash
# Clone the repo
git clone https://github.com/Aman123lug/my-portfolio.git

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
